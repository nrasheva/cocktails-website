## Features

- Authentication
- Save favorite cocktails
- Admin / Authorization
- Recipes

## Run locally

Clone the project

```bash
git clone https://github.com/nrasheva/cocktails-website
```

Go to the project directory

```bash
cd cocktails-website
```
Install the dependencies

```bash
npm install
```
Start the server

```bash
npm run dev
```
